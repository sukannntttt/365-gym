# KINETIC Tech Stack

Comprehensive breakdown of the technologies used in the KINETIC high-performance gym platform.

## 1. Core Architecture
- **Environment**: Node.js (v20+ Recommended)
- **Monolithism**: Decoupled Client-Server Monopackage.
- **Protocol**: RESTful HTTP/JSON.

## 2. Frontend Layer (Performance & Interface)
The frontend is engineered for brute performance and tactile interaction using high-fidelity web standards.

| Component | Technology | Description |
| :--- | :--- | :--- |
| **Logic** | Vanilla JavaScript (ES6+) | Modern asynchronous DOM manipulation. |
| **Styling** | Tailwind CSS | Utility-first layout engine for responsive monolithism. |
| **3D Rendering** | Custom CSS3 | CSS Variables, Perspective, and 3D Transformations for tactile UI. |
| **Iconography** | Material Symbols | Dynamic, high-fidelity Google Icons. |
| **Typography** | Google Fonts | `Lexend` (Headline) and `Inter` (Body). |
| **Analytics** | Chart.js (Planned) | High-performance canvas-based data visualizations. |

## 3. Backend Layer (API & Logic)
A secure Node.js ecosystem providing high-intensity data processing.

| Dependency | Version | Role |
| :--- | :--- | :--- |
| **`express`** | `^5.2.1` | High-performance routing and middleware. |
| **`jsonwebtoken`** | `^9.0.3` | Stateless athlete authentication. |
| **`bcryptjs`** | `^3.0.3` | Secure crypt-based credential hashing. |
| **`resend`** | `^6.10.0` | Transactional email delivery and notifications. |
| **`cors`** | `^2.8.6` | Cross-origin resource sharing control. |
| **`nodemon`** | `^3.1.14` | Hot-reloading development environment. |

## 4. Data Layer (Persistence & Intelligence)
- **Database**: MongoDB (Local or Atlas Distributed Clusters).
- **ODM**: **Mongoose** (`^9.3.3`) for high-fidelity data validation and modeling.
- **Seeding Engine**: Custom script (`backend/seed.js`) for initializing gym protocols and Indian diet plans.

## 5. Development & Deployment
- **Git / GitHub**: Atomic commit history and version control.
- **Render / Netlify**: Automated CI/CD for backend and static frontend.
- **Postman / Insomnia**: API protocol testing.
