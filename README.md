# KINETIC Gym | Performance Monolith

## Overview
**KINETIC** is a premium, high-performance fitness ecosystem designed for elite athletes and training facilities. It features a brutalist 3D UI, personalized Indian meal plans (vegetarian/non-vegetarian), and comprehensive performance analytics.

## Key Features
- **3D Tactile Interface**: Physical buttons, carved inputs, and lighting-aware cards.
- **Nutritional Intelligence**: Personalized Indian diet plans with real-time macronutrient breakdown.
- **Workout Evolution**: Detailed logging of training volume and intensity.
- **Membership Protocols**: Tiered membership levels (Basic, Elite Kinetic, Monolith).

## Tech Stack
- **Frontend**: HTML5, Vanilla JavaScript, Tailwind CSS, Custom CSS.
- **Backend**: Node.js, Express.js, MongoDB (Mongoose), JWT.

## Setup Instructions
1. **Repository Initialization**: Clone and install dependencies.
   ```bash
   npm install
   ```
2. **Environment Configuration**: Configure `.env` in the `backend` directory.
3. **Database Seeding**: Initialize the gym protocols and initial diet plans.
   ```bash
   node backend/seed.js
   ```
4. **Launch Server**:
   ```bash
   npm start
   ```

## Design Language
- **Brutalist Monolith**: Dark mode, monochromatic with neon accents.
